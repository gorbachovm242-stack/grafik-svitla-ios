**«Графік світла» для iPhone — окремий застосунок, тестова версія.** Графік відключень вашої черги, таймер до зміни,
віджети на робочий екран і екран блокування, повітряна тривога й Live Activity під час неї. Потрібен iOS 17 або новіший.

Цей файл ставиться без App Store: його підписує ваш власний Apple ID через програму-посередника. Платити не треба.
На справжньому iPhone застосунок ще перевіряють, тож пишіть, що не так.

### Як поставити (потрібен компʼютер, один раз)

1. Завантажте файл `GrafikSvitla-….ipa` нижче, у розділі Assets.
2. На компʼютері поставте **Sideloadly** (sideloadly.io) або **AltStore** (altstore.io; на компʼютер — AltServer).
   На Windows для обох потрібні iTunes та iCloud із сайту Apple, а не з Microsoft Store.
3. Підключіть iPhone кабелем, відкрийте в програмі файл `.ipa`, введіть свій Apple ID і почніть установку.
4. На iPhone: Параметри → Загальні → VPN і керування пристроями → свій Apple ID → «Довіряти».
   Якщо попросить, увімкніть Параметри → Приватність і безпека → «Режим розробника» (iPhone перезавантажиться).

### Перше налаштування

1. Відкрийте «Графік світла» → вкладка «Світло» → «Моя черга»: оберіть область і чергу. Дозвольте сповіщення.
2. Віджет: утримуйте порожнє місце на робочому екрані → «Редагувати» → «Додати віджет» → «Графік світла».
3. Тривога: вкладка «Тривога» → «Показувати у віджеті» → оберіть область, район і громаду.

### Що варто знати

- Застосунок, підписаний безкоштовним Apple ID, працює **7 днів**, потім його треба підписати знову тією ж програмою
  (AltStore робить це сам, коли компʼютер з AltServer у тій самій Wi-Fi). Одночасно можна мати до 3 таких застосунків.
- Live Activity тривоги зʼявляється, коли ви відкриваєте застосунок під час тривоги; «↻» на ній оновлює стан.
- Сирени застосунок не подасть: для цього офіційний застосунок «Повітряна тривога».
- Якщо віджет пише «Оберіть чергу», хоча в застосунку її обрано, — повідомте, це важливо для тесту.
